# Деплой и инфраструктура

## Деплой

- **Деплой выполняется как обычно**: репозиторий подключён к Railway, изменения в `main` автоматически триггерят новый деплой.
- **CLI-деплой не использовать**: не настраивать и не документировать деплой через Railway CLI; достаточно push в GitHub.
- Переменные окружения задаются в Railway (Variables) для сервиса `i_make_nails`; секреты не хранить в коде и не коммитить.

## Среда

- Backend: один процесс (aiohttp + aiogram webhook), порт из `PORT`, healthcheck `/health`.
- База: PostgreSQL (Railway managed); миграции — Alembic, при необходимости запуск при старте или отдельным шагом.
